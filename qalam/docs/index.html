Qalam (قلم) Template Engine

An enterprise-grade, AST-based HTML template engine for the Djazair Programming Language. Built with clean modular architecture, In-Memory AST Caching, expressive UNIX-style filter pipelines, and automatic XSS escaping.

Qalam v0.2.0 195/195 Tests Passed Auto XSS Escaped AST Caching

Overview & Philosophy

Qalam (قلم) is the standard HTML template engine for Djazair applications. Inspired by modern, battle-tested engines like Jinja2, Twig, Blade, and Liquid, Qalam brings clean layout inheritance, chained data transformations, and high-throughput execution to web backends, emails, and CLI tools.

XSS-Safe by Default

Every {{ var }} interpolation is automatically encoded for HTML special characters. Raw HTML output is strictly opt-in via {{{ raw }}}.

AST Memory Caching

Templates are parsed once into an Abstract Syntax Tree (AST) and reused across requests, delivering up to 30x faster rendering in production.

Filter Piping Pipeline

Transform and format values smoothly using chained pipes: {{ title | trim | capitalize }} with full support for custom filters.

Layout Inheritance

Define master application layouts with {% extends %} and customize sections with overrideable {% block %} tags.

Installation

Install Qalam into your Djazair project using the official package manager:

Terminal 
dpm install qalam

Quick Start

1. In-Memory Rendering (No Files Needed)

Render dynamic strings directly in memory with full AST evaluation:

memory_render.dz 
use qalam

let template = "Hello, {{ user.name | capitalize }}! Your balance is ${{ balance | round(2) }}."
let context = {
    "user": {"name": "riad"},
    "balance": 125.789
}

let result = qalam.renderString(template, context)
print(result)
# Output: Hello, Riad! Your balance is $125.79.

2. File-Based Rendering with Layouts

app.dz 
use qalam

# Initialize View engine with views directory and cache
let view = new qalam.View({
    "views": "views",
    "cache": True
})

let html = view.render("dashboard", {
    "pageTitle": "Trading Overview",
    "user": {"name": "Riad", "role": "admin"}
})

Modular Architecture & Pipeline

Qalam is structured into decoupled, single-responsibility modules located in core/:

Module File Primary Role
Lexer core/lexer.dz Tokenizes raw text into clean semantic token streams, strips comments, handles whitespace.
Parser core/parser.dz Builds the hierarchical Abstract Syntax Tree (AST), handles if/elif/else, for, and blocks.
Evaluator core/evaluator.dz Evaluates AST nodes, dot-paths, logical operators (and/or), loop context, and filter pipes.
Loader core/loader.dz Enforces directory security boundaries against traversal attacks and manages in-memory AST caching.
Filters core/filters.dz Provides 18+ built-in transformations and allows registering custom filter callbacks.
Escaper core/escaper.dz High-speed entity encoding to prevent Cross-Site Scripting (XSS).
View core/view.dz Unified facade orchestrating the entire lifecycle.

Variables & Escaping

Variables enclosed in {{ ... }} are evaluated against the data context and automatically sanitized against XSS injection:

template.html 
<!-- Auto-escaped: safe against <script> and injection -->
<h1>Hello, {{ user.name }}</h1>

<!-- Nested dot paths and array bracket indexing -->
<p>City: {{ user.profile.address.city }}</p>
<p>First item: {{ articles[0].title }}</p>

<!-- Raw unescaped HTML: Use only for trusted content -->
<div class="content">{{{ article.trustedHtmlBody }}}</div>

Filters & Piping Pipeline

Transform data directly in your templates using the pipe operator (|). Multiple filters can be chained sequentially:

filters.html 
<!-- Single and chained filters -->
<h1>{{ article.title | trim | title }}</h1>
<p>Author: {{ author.name | default("Anonymous") }}</p>
<p>Tags: {{ tags | join(" • ") | upper }}</p>
<p>Price: ${{ product.price | round(2) }}</p>
Piping Order: Transformations execute from left to right. In {{ text | trim | upper }}, the text is first trimmed, and the result is converted to uppercase.

Conditionals & Native Djazair Operators

Qalam is fully compatible with Djazair language operators, including logical operators (and, &&, or, ||, not, !), comparison operators (==, !=, <, <=, >, >=), membership (in, not in), identity (is, is not), and inline ternary expressions:

conditionals.html 
<!-- Multi-branch conditionals with membership and identity -->
{% if 'admin' in user.roles and (user.isStaff or user.isSuper) %}
    <span class="badge badge-admin">Master Administrator</span>
{% elif user.token is not Null and user.status not in bannedStatuses %}
    <span class="badge badge-editor">Active Member: {{ user.firstName + ' ' + user.lastName }}</span>
{% elif not user.isVerified %}
    <span class="badge badge-warning">Pending Verification</span>
{% else %}
    <span class="badge badge-user">Standard Guest</span>
{% endif %}

<!-- Native Djazair Ternary: if cond ? a else b -->
<p>Status: {{ if user.isAdmin ? 'Administrator' else 'Member' }}</p>

<!-- Standard Ternary: cond ? a : b -->
<p>Score: {{ score >= 50 ? 'Passed' : 'Failed' }}</p>

Loops & `loop` Metadata

Iterate over arrays using {% for item in collection %} with automatic access to the loop context object and optional {% else %} fallback:

loops.html 
<ul>
{% for item in items %}
  <li class="{% if loop.first %}first-item{% endif %} {% if loop.even %}even{% else %}odd{% endif %}">
    Item #{{ loop.index }} of {{ loop.length }}: {{ item.name }}
  </li>
{% else %}
  <li>No items found in list.</li>
{% endfor %}
</ul>
Property Type Description
loop.indexInteger1-based iteration index (1, 2, 3...)
loop.index0Integer0-based iteration index (0, 1, 2...)
loop.firstBooleanTrue during the first iteration
loop.lastBooleanTrue during the last iteration
loop.lengthIntegerTotal number of elements in the collection
loop.evenBooleanTrue if 1-based iteration is even (2, 4, 6...)
loop.oddBooleanTrue if 1-based iteration is odd (1, 3, 5...)

Layout Inheritance & Blocks

Create structured, DRY templates by inheriting from master layouts with {% extends %} and {% block %}:

views/layouts/base.html 
<!DOCTYPE html>
<html>
<head>
  <title>{% block title %}Default App{% endblock %}</title>
</head>
<body>
  <header>{% block header %}<nav>Default Navigation</nav>{% endblock %}</header>
  <main>
    {% block content %}{% endblock %}
  </main>
  <footer>{% block footer %}© 2026 Djazair Language{% endblock %}</footer>
</body>
</html>
views/home.html 
{% extends "layouts/base" %}

{% block title %}Dashboard — {{ siteName }}{% endblock %}

{% block content %}
  <h1>Welcome back, {{ user.name }}!</h1>
  <p>Manage your account and settings.</p>
{% endblock %}

    {% include "partials/sidebar" %}
    <div class="content">...</div>
  </div>

Comments & Whitespace Control

Template comments inside {# ... #} are stripped during tokenization and never appear in HTML output:

template.html 
{# This internal note will not be rendered in the browser #}
<p>Visible Content</p>

<!-- Whitespace trimming using hyphens -->
Hello   {{- user.name -}}   World
<!-- Output: HelloRiadWorld -->

Custom Filter Registration

Register application-specific domain filters directly on the View instance:

custom_filters.dz 
use qalam

let view = new qalam.View({})

# Register a custom currency filter
view.registerFilter("currency", fn(val, args = [])
    let symbol = if args.length() > 0 ? str(args[0]) else "DZD"
    return str(val) + " " + symbol
end)

# Register a custom date formatter
view.registerFilter("datePrefix", fn(val, args = [])
    return "Date: " + str(val)
end)

let html = view.renderString("<p>Price: {{ total | currency('DZD') }}</p>", {"total": 15000})
print(html)
# Output: <p>Price: 15000 DZD</p>

View & API Reference

Class: qalam.View(config = {})

Config Option Type Default Description
"views" String "views" Root filesystem directory for template files.
"cache" Boolean True Enables in-memory compiled AST caching.

Public Methods

  • v.render(templateName, data = {}) -> String — Renders a template file.
  • v.renderString(templateString, data = {}, blocksMap = {}) -> String — Renders in memory.
  • v.registerFilter(name, callback) — Registers a custom transformation filter.
  • v.getSafePath(templateName) -> String — Resolves and validates directory containment.
  • v.readFile(templateName) -> String — Reads template file text content.
  • v.clearCache() — Flushes the compiled AST memory cache.

Global Helper Functions

  • qalam.renderString(tpl, data, blocks) -> String — Quick in-memory template rendering.
  • qalam.escapeHtml(value) -> String — Encodes HTML special characters to prevent XSS.

Security Model

Threat Vector Mitigation Mechanism
Cross-Site Scripting (XSS) All {{ ... }} tags automatically sanitize &, <, >, ", '.
Directory Traversal (../) TemplateLoader.getSafePath() enforces strict directory boundary containment.
Null-Byte Injection Null characters in template identifiers are detected and rejected.

Performance & AST Caching

Under production workloads, repeatedly reading from disk and tokenizing templates creates CPU overhead. Qalam features an automatic **In-Memory AST Cache**:

High Throughput: On the first render, Qalam compiles the template into an AST and stores it in memory. All subsequent requests execute directly from memory, achieving up to 30x higher requests-per-second.

Kasbah Web Framework Integration

Qalam is the native template engine powering the Kasbah web framework:

server.dz 
use kasbah

let app = new kasbah.app({"views": "views"})

app.get("/profile", fn(req, res)
    # Automatically delegates to Qalam View engine
    res.view("profile", {
        "title": "User Dashboard",
        "user": req.session.get("user")
    })
end)

app.listen(8080)

Production Recipes & Best Practices

Recipe 1: Transactional HTML Email Template

email_invoice.dz 
use qalam

let emailTpl = `
<h1>Invoice #{{ invoiceId }}</h1>
<p>Dear {{ customer.name | capitalize }},</p>
<p>Thank you for your order on {{ orderDate }}.</p>

  <tr><th>Item</th><th>Price</th></tr>
  {% for item in items %}
  <tr>
    <td>{{ item.name }}</td>
    <td>\${{ item.price | round(2) }}</td>
  </tr>
  {% endfor %}
</table>
<p><strong>Total: \${{ total | round(2) }}</strong></p>
`

let emailHtml = qalam.renderString(emailTpl, {
    "invoiceId": "INV-2026-08",
    "customer": {"name": "riad harizi"},
    "orderDate": "2026-08-21",
    "items": [
        {"name": "Djazair Pro License", "price": 199.99},
        {"name": "Kasbah Cloud Hosting", "price": 49.50}
    ],
    "total": 249.49
})
