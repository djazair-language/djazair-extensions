High-Resilience System Clipboard for Djazair

The Djazair Clipboard Extension provides native, cross-platform clipboard integration engineered with transient lock retry loops, full binary-safe Unicode (UTF-8) translation, instant \(O(1)\) sequence change detection, and format introspection.

Win32 Retry Loop

10-attempt retry with backoff eliminates errors from transient OS locks.

Full UTF-8 & Unicode

Flawless handling of Arabic, Asian glyphs, emojis, and multiline text.

\(O(1)\) Change Tracking

Detect clipboard updates instantly via serial sequence numbers.

Format Introspection

Query available clipboard formats (unicode, plain text, bitmaps, files).

Defensive Type Safety

Built-in type assertions through the standard assert library.

Zero Dependencies

Direct Win32 API on Windows, native pipes on Linux and macOS.

Installation & Build

How to compile the native shared object and import it into your Djazair programs.

PowerShell / Command Prompt 
# Build clipboard.dll using GCC (MinGW-w64)
cd extensions/clipboard
.\build.bat "D:\Programing\Djazair Programming Language\djazair-language"

# Output will create clipboard.dll linked against libdjazair and user32

cd extensions/clipboard
chmod +x build.sh
./build.sh /path/to/djazair-language
Terminal 
# Install via Djazair Package Manager
dpm install clipboard

# Compile native binary
dpm build clipboard

Quick Start Guide

Basic copy, paste, check, and clear in under 10 lines of Djazair code.

quick_start.dz 
use clipboard

# 1. Copy UTF-8 string to clipboard
clipboard.copy("مرحبا بالعالم — Hello from Djazair 🇩🇿")

# 2. Retrieve the text
let text = clipboard.paste()
print("Clipboard Content: " + text)

# 3. Check if text is available
if clipboard.has()
    print("Text format is present on clipboard.")
end

# 4. Clear all clipboard data
clipboard.clear()
print("Has text after clear: " + str(clipboard.has()))

Core Methods Detail

clipboard.copy(text) → Bool
Core Method

Writes the given UTF-8 string into the system clipboard. On Windows, allocates movable global memory (HGLOBAL), converts the text to UTF-16 wide characters, empties existing contents, and registers the data under CF_UNICODETEXT.

Parameter Type Required Description
text String Yes The UTF-8 text string to be copied into the clipboard.
Defensive Type Assertion: If a non-string value (e.g., Number, Array, or Null) is passed to copy(), a descriptive TypeError exception is thrown immediately via assert.string().
Djazair Example 
use clipboard

let ok = clipboard.copy("Hello, World!")
if ok
    print("Copied successfully!")
end
clipboard.paste() → String
Core Method

Reads and converts text currently stored in the clipboard to a UTF-8 string. If the clipboard is empty, locked, or contains only non-text formats (such as raw bitmaps), it safely returns an empty string ("").

Djazair Example 
use clipboard

let content = clipboard.paste()
if content != ""
    print("Pasted content: " + content)
else
    print("Clipboard does not contain any readable text.")
end
clipboard.clear() → Bool
Core Method

Flushes all contents and handles from the system clipboard. On Windows, calls EmptyClipboard() within a resilient retry loop.

Djazair Example 
use clipboard

clipboard.clear()
print("Clipboard cleared. hasText = " + str(clipboard.hasText()))
clipboard.has() → Bool
Core Method

Checks whether text data is present in the clipboard without retrieving or allocating the entire string. Tests both CF_UNICODETEXT and CF_TEXT formats.

Djazair Example 
use clipboard

if clipboard.has()
    print("Found text: " + clipboard.paste())
end

Introspection & Tracking Detail

clipboard.sequenceNumber() → Number
O(1) Check

Returns a 32-bit integer representing the OS clipboard sequence counter. The operating system increments this counter whenever the clipboard contents change. This enables ultra-low-overhead change detection (\(O(1)\)) in polling loops or GUI timers without allocating memory or locking the clipboard.

Djazair Example 
use clipboard

let seq1 = clipboard.sequenceNumber()
clipboard.copy("Payload A")
let seq2 = clipboard.sequenceNumber()

print("Sequence incremented: " + str(seq2 > seq1)) # Prints: True
clipboard.formats() → Array
Introspection

Enumerates all data formats currently registered on the clipboard and returns them as an array of human-readable string tokens. Known standard formats are mapped automatically:

Format Token Win32 Constant Data Type
"unicode"CF_UNICODETEXTUTF-16 Unicode text
"text"CF_TEXTANSI plain text
"oem_text"CF_OEMTEXTOEM character set text
"bitmap"CF_BITMAPDevice-dependent bitmap
"dib" / "dibv5"CF_DIB / CF_DIBV5Device-independent bitmap image
"files"CF_HDROPFile list drop handle (Explorer)
"locale"CF_LOCALELocale identifier
"custom" / nameRegisteredApplication-specific registered format (e.g. HTML Format)
Djazair Example 
use clipboard

clipboard.setText("Testing format detection")
let formatsList = clipboard.formats()

for fmt in formatsList
    print("  - Available format: " + fmt)
end

System Architecture & Internals

How Djazair achieves industrial reliability across Windows, Linux, and macOS.

Windows (Win32 user32.dll)

Direct low-level C calls to OpenClipboard, EmptyClipboard, GetClipboardData(CF_UNICODETEXT), and GlobalAlloc. Zero process spawning.

Linux (Wayland & X11)

Automatic environment sniffing: uses wl-copy/wl-paste if WAYLAND_DISPLAY is active, otherwise falls back seamlessly to xclip or xsel.

macOS (AppKit Pipes)

Clean streaming integration using the native pbcopy and pbpaste utilities pre-installed on all Apple macOS versions.

The Win32 Transient Lock Retry Loop

In Windows desktop environments, background applications (such as Microsoft Office, clipboard managers, or browser extensions) frequently open the clipboard briefly to inspect format changes. A naive call to OpenClipboard(NULL) will immediately fail if triggered simultaneously.

To resolve this, the Djazair native engine implements an automatic backoff retry loop:

C Engine Snippet (src/clipboard.c)
static BOOL open_clipboard_with_retry(HWND owner) {
    for (int i = 0; i < 10; i++) {
        if (OpenClipboard(owner)) return TRUE;
        Sleep(5); // Wait 5ms for other processes to release the clipboard
    }
    return FALSE;
}

Practical Workflows

Production code patterns for building clipboard monitors, multilingual apps, and safe integrations.

Non-Blocking Clipboard Change Monitor

Use sequenceNumber() in an event loop or background worker. Because checking the sequence counter does not open or lock the clipboard, it has practically zero CPU overhead and will never conflict with other applications.

monitor_clipboard.dz 
use clipboard

let lastSeq = clipboard.sequenceNumber()
print("Clipboard monitor started (sequence: ${lastSeq})...")

# In your event loop or periodic timer:
fn onTick()
    let currentSeq = clipboard.sequenceNumber()
    if currentSeq != lastSeq
        lastSeq = currentSeq
        if clipboard.hasText()
            print("[Update Detected] New text: " + clipboard.getText())
        end
    end
end

Arabic & Multilingual Unicode Processing

Djazair clipboard uses native Windows CP_UTF8 conversion to and from wide strings, guaranteeing perfect preservation of right-to-left Arabic characters, diacritics (Harakat), and symbols.

unicode_demo.dz 
use clipboard

let arabicText = "الجمهورية الجزائرية الديمقراطية الشعبية 🇩🇿"
clipboard.setText(arabicText)

let restored = clipboard.getText()
print("Restored Text: " + restored)
print("Matches Original: " + str(restored == arabicText))

Defensive Error Handling

Wrap untrusted user inputs with try ... catch blocks to gracefully intercept invalid argument types.

safe_copy.dz 
use clipboard

fn safeCopy(input)
    try
        clipboard.copy(input)
        return True
    catch err
        print("[Clipboard Warning] Invalid input type: " + str(err))
        return False
    end
end

safeCopy("Valid text") # Success
safeCopy(12345)        # Caught and reported gracefully
