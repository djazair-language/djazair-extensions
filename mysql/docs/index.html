Overview & Architecture

Understand how the Djazair MySQL hybrid extension bridges high-level Djazair scripts with the raw C MySQL client engine.

The Djazair MySQL Extension follows a hybrid two-tier architectural pattern. The upper tier consists of high-level Djazair object-oriented classes (Connection and ResultSet), while the bottom tier is a compiled C99 dynamic library (mysql.dll / mysql.so) compiled against the standard libmysqlclient or MariaDB Connector/C.

High-Level Djazair Layer

Provides clean, modern syntax with runtime assertions (assert.string, assert.array), automatic utf8mb4 character set configuration, safe parameterized query construction, and associative map conversion.

C Native Bridge

Provides direct C socket communication through mysql_real_connect, mysql_real_query, and mysql_store_result. Resources are encapsulated in Djazair VM native resource objects (MYSQLConn and MYSQLRes).

Security Layer

All parameterized inputs passed to safeQuery() or safeExecute() are processed through mysql_real_escape_string using the active connection's character set, completely neutralizing SQL injection vectors.

Automatic UTF-8 Multibyte Encoding (utf8mb4): Immediately upon successful connection, the driver automatically executes mysql_set_character_set(conn, "utf8mb4"). This ensures 100% full support for international languages, Arabic characters, and modern 4-byte emojis without any character corruption or truncation.

Installation & Compiling

How to compile and deploy the MySQL extension from source on Windows and Linux.

The extension can be built effortlessly using the provided build scripts. It automatically locates MySQL or MariaDB include headers and client libraries on your machine.

Quick Start Guide

Connect to a MySQL instance, create a table, insert records safely, and read data in under 20 lines of Djazair code.

quickstart.dz 
use mysql

# 1. Establish connection to local or remote MySQL/MariaDB server
let db = mysql.connect("localhost", "root", "secret123", "testdb", 3306)

if db.isConnected()
    print("Successfully connected to MySQL: " + db.serverInfo())

    # 2. Execute DDL statement
    db.execute("CREATE TABLE IF NOT EXISTS users (id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(100), balance DECIMAL(10,2))")

    # 3. Insert record using safe parameterization (Anti-SQL Injection)
    let ok = db.safeExecute("INSERT INTO users (name, balance) VALUES (?, ?)", ["Riad Harizi", 1500.50])
    if ok
        print("Inserted user ID: " + str(db.insertId()))
        print("Affected rows: " + str(db.affectedRows()))
    end

    # 4. Query records and fetch as associative maps
    let res = db.safeQuery("SELECT * FROM users WHERE balance >= ?", [1000.0])
    if !isNull(res)
        let rows = res.fetchAllAssoc()
        for user in rows
            print("User: " + user["name"] + " | Balance: $" + str(user["balance"]))
        end
        res.close() # Free result memory buffer
    end

    # 5. Gracefully close connection socket
    db.close()
else
    print("Database connection error: " + db.error())
    print("Error code: " + str(db.errno()))
end

Connection Class API

Manage database session connections, credential configuration, socket states, and connection metadata.

class Connection(host, user, password, db, port = 3306)
Connection

Instantiates and opens a new connection to a MySQL or MariaDB database server. Validates that all arguments are of expected types using assert, initializes the underlying C MYSQL* pointer, establishes the connection socket, and immediately sets the connection charset to utf8mb4. You can also use the shorthand factory function mysql.connect(...).

Parameter Type Default Description
host String Required Hostname or IP address (e.g. "localhost", "127.0.0.1", "db.casbah.dz").
user String Required Database authentication username.
password String Required User authentication password (or empty string "").
db String Required Target database catalog name.
port Number 3306 TCP port number on which MySQL daemon is listening.
Example 
use mysql

# Style A: Explicit constructor instantiation
let db1 = new mysql.Connection("localhost", "root", "rootpass", "ecommerce", 3306)

# Style B: Shorthand helper factory
let db2 = mysql.connect("192.168.1.50", "admin", "P@ssw0rd!", "analytics", 3307)
isConnected()  |  ping()
Bool

isConnected() returns True if the internal socket connection flag is currently active. ping() transmits a live test ping packet to the server via mysql_ping(); if the server connection is still responsive, it returns True.

Example 
if db.isConnected()
    if db.ping()
        print("Database server connection is active and responsive.")
    else
        print("Database server dropped connection.")
    end
end
error()  |  errno()
String / Number

error() returns the last error string reported by the MySQL client or server. If the connection failed during initialization, it returns the startup diagnostic message. errno() returns the numeric MySQL error code (e.g. 1045 for Access Denied, 1062 for Duplicate Key).

Example 
let ok = db.execute("INVALID SQL STATEMENT")
if !ok
    print("MySQL Error (" + str(db.errno()) + "): " + db.error())
end
serverInfo()  |  hostInfo()
String

serverInfo() returns the version string of the connected MySQL server (e.g. "8.0.35", "10.11.4-MariaDB"). hostInfo() returns a string describing the connection type and endpoint (e.g. "localhost via TCP/IP" or "Localhost via UNIX socket").

Example 
print("Server Version : " + db.serverInfo())
print("Host Transport : " + db.hostInfo())
setCharset(charset)
Bool

Sets the default character set for the current connection socket via mysql_set_character_set() (for example, "utf8mb4", "utf8", or "latin1"). Note that Connection.init() automatically initializes the charset to utf8mb4 upon successful connection. Returns True if the charset was updated successfully.

Example 
let ok = db.setCharset("utf8mb4")
if ok
    print("Charset successfully switched to utf8mb4")
end
stat(), threadId(), clientInfo(), protocolInfo()
String / Number

Provides comprehensive low-level diagnostic insights into the active MySQL socket and client library:

  • stat(): Returns a formatted status string containing server uptime, active threads, total queries, and memory statistics.
  • threadId(): Returns the unique server-assigned thread ID for the current connection session.
  • clientInfo(): Returns the client library compilation version (e.g. "8.0.35").
  • protocolInfo(): Returns the MySQL client/server communication protocol version number (typically 10).
Example 
print("Connection Thread ID: " + str(db.threadId()))
print("Protocol Version    : " + str(db.protocolInfo()))
print("Client Version      : " + db.clientInfo())
print("Server Stats        :\n" + db.stat())
close()
Void

Gracefully terminates the connection with the MySQL server, closes the underlying TCP socket, releases all allocated native memory buffers, and sets the internal C pointer to NULL to prevent double-free or use-after-free conditions. Safe to call multiple times.

Example 
# Always close connection when finished to free server socket resources
db.close()
print("Connection closed: " + str(!db.isConnected()))

Queries & Parameterized Execution

Execute safe parameterized statements, raw queries, prevent SQL injection, and read execution metadata.

safeQuery(sql, params = [])
ResultSet | Null

Executes a parameterized SELECT query. Replaces all question mark (?) placeholders in the SQL string with properly escaped parameter values. Automatically handles Null as SQL NULL, numbers as unquoted or escaped numerals, and strings safely escaped using mysql_real_escape_string. Returns a new ResultSet on success, or Null on failure.

Example 
let minPrice = 150.0
let category = "Electronics"

let res = db.safeQuery(
    "SELECT id, title, price FROM products WHERE price >= ? AND category = ? ORDER BY price ASC",
    [minPrice, category]
)

if !isNull(res)
    let products = res.fetchAllAssoc()
    for p in products
        print(p["title"] + " - $" + str(p["price"]))
    end
    res.close()
end
safeExecute(sql, params = [])
Bool

Executes a parameterized non-SELECT statement (INSERT, UPDATE, DELETE, REPLACE, DDL). Substitutes ? placeholders with sanitized parameters, updates the internal affected rows count, and returns True if the query succeeded, or False if an error occurred.

Example 
# Insert new employee record safely
let ok = db.safeExecute(
    "INSERT INTO employees (name, department, salary, notes) VALUES (?, ?, ?, ?)",
    ["Amine Brahimi", "Engineering", 3200.0, Null]
)

if ok
    print("New Employee ID: " + str(db.insertId()))
    print("Rows affected  : " + str(db.affectedRows()))
else
    print("Failed to insert: " + db.error())
end
query(sql)  |  execute(sql)
ResultSet / Bool

Executes a raw SQL string without parameter replacement. Use query(sql) for SELECT queries returning a ResultSet, and execute(sql) for non-returning statements (DDL schema definitions, TRUNCATE, ALTER TABLE, etc.).

Security Warning: Never concatenate unsanitized user inputs into query() or execute(). Always use safeQuery() or safeExecute() to protect your database against SQL Injection attacks.
Example 
# Schema creation via raw execute
db.execute("CREATE TABLE IF NOT EXISTS audit_log (id INT AUTO_INCREMENT PRIMARY KEY, action TEXT, ts TIMESTAMP DEFAULT CURRENT_TIMESTAMP)")

# Fetch system variables via raw query
let res = db.query("SHOW VARIABLES LIKE 'version%'")
if !isNull(res)
    let vars = res.fetchAllAssoc()
    for v in vars
        print(v["Variable_name"] + " = " + v["Value"])
    end
    res.close()
end
escape(s)
String

Directly invokes mysql_real_escape_string using the active connection socket. Escapes special SQL characters including null byte (\0), newline (\n), carriage return (\r), backslash (\\), single quote (\'), double quote (\"), and Control-Z.

Example 
let rawInput = "O'Connor and Sons \x00 \"Enterprise\""
let sanitized = db.escape(rawInput)
# Returns: "O\'Connor and Sons \\0 \\\"Enterprise\\\""
affectedRows(), insertId(), raw()
Number / Resource

Provides metadata after statement execution:

  • affectedRows(): Returns the number of rows changed, deleted, or inserted by the last DML statement.
  • insertId(): Returns the AUTO_INCREMENT primary key ID generated by the most recent INSERT statement.
  • raw(): Returns the underlying C MYSQL* resource handle for advanced native C interop or extension plugins.
Example 
db.safeExecute("UPDATE accounts SET status = 'Archived' WHERE balance = 0")
print("Archived accounts: " + str(db.affectedRows()))

ACID Transaction Management

Guarantee data integrity, atomicity, consistency, and durability using transaction blocks.

beginTransaction(), commit(), rollback()
Bool

beginTransaction() disables MySQL autocommit mode (mysql_autocommit(conn, 0)), initiating an atomic transaction block. Multiple statements can then be executed sequentially. Calling commit() persists all changes permanently and restores autocommit. Calling rollback() cancels and discards all pending changes in the transaction.

Production Bank Transfer Pattern 
use mysql

let db = mysql.connect("localhost", "root", "", "banking", 3306)

if db.isConnected()
    let senderId = 101
    let receiverId = 202
    let transferAmount = 350.0

    # 1. Begin atomic transaction block
    if db.beginTransaction()
        # Deduct from sender
        let step1 = db.safeExecute("UPDATE accounts SET balance = balance - ? WHERE id = ? AND balance >= ?", [transferAmount, senderId, transferAmount])
        
        # Credit to receiver
        let step2 = db.safeExecute("UPDATE accounts SET balance = balance + ? WHERE id = ?", [transferAmount, receiverId])

        # Record audit log
        let step3 = db.safeExecute("INSERT INTO transfer_logs (from_id, to_id, amount) VALUES (?, ?, ?)", [senderId, receiverId, transferAmount])

        # Verify all steps succeeded and affected exactly expected rows
        if step1 and step2 and step3 and db.affectedRows() > 0
            if db.commit()
                print("Transfer successfully committed! Total: $" + str(transferAmount))
            else
                print("Commit failed, rolling back: " + db.error())
                db.rollback()
            end
        else
            print("Transaction aborted due to insufficient balance or error. Rolling back.")
            db.rollback()
        end
    else
        print("Could not begin transaction: " + db.error())
    end

    db.close()
end

ResultSet Class API

Stream, traverse, seek, and convert query records into Djazair Arrays and Associative Maps.

numRows(), numFields(), columns()
Number / Array

numRows() returns total record count stored in the result buffer. numFields() returns the number of columns in the schema. columns() returns an array of column name strings (e.g. ["id", "name", "email"]).

Example 
let res = db.query("SELECT id, name, email, role FROM users")
if !isNull(res)
    print("Total Rows   : " + str(res.numRows()))
    print("Total Columns: " + str(res.numFields()))
    print("Column Names : " + str(res.columns()))
    res.close()
end
fetchRow()  |  fetchAssoc()
Array / Map | Null

fetchRow() advances the internal cursor and returns the next record as a 0-indexed Djazair Array ([val0, val1, ...]). fetchAssoc() returns the next record as an associative map indexed by column name ({"id": "1", "name": "Riad"}). Returns Null when cursor reaches the end.

Example 
let res = db.query("SELECT id, name, balance FROM users")

# 1. Fetch individual rows sequentially with fetchAssoc()
let user = res.fetchAssoc()
while !isNull(user)
    print("User: " + user["name"] + " has balance $" + str(user["balance"]))
    user = res.fetchAssoc()
end

res.close()
fetchAll()  |  fetchAllAssoc()
Array

Iterates through all remaining records in the buffer. fetchAll() returns an array of row arrays ([[1, "A"], [2, "B"]]). fetchAllAssoc() returns an array of associative maps. Perfect for returning API datasets or JSON serialization.

Example 
let res = db.query("SELECT id, name FROM users LIMIT 10")
let allUsers = res.fetchAllAssoc()

for u in allUsers
    print("#" + str(u["id"]) + " -> " + u["name"])
end

res.close()
seek(offset)  |  close()
Void

seek(offset) moves the internal row cursor to a 0-based row index, enabling instant rewind (seek(0)) or jumping to arbitrary offsets. close() invokes mysql_free_result on the C engine, freeing buffer memory and nullifying the internal handle.

Example 
let res = db.query("SELECT name FROM items")

# Pass 1: Print items
let rows = res.fetchAll()

# Rewind cursor back to start
res.seek(0)

# Pass 2: Re-read first row
let first = res.fetchRow()
print("First item was: " + str(first[0]))

# Free C memory buffer
res.close()

Low-Level C Engine Architecture

Internal implementation details of the C99 native bridge and C resource memory lifecycles.

The C engine source resides in extensions/mysql/src/. All entrypoints communicate with the Djazair Virtual Machine through the djazair_api.h C header:

C Source File Responsibility Core Native Functions
mysql.c Module registration & dispatch table DJAZAIR_EXTENSION(mysql, mysql_module_funcs)
mysql_conn.c Connection lifecycle & socket diagnostics mysqlInitNative, mysqlRealConnectNative, mysqlSetCharsetNative, mysqlCloseNative, mysqlPingNative, mysqlStatNative, mysqlThreadIdNative
mysql_query.c Query execution, transactions, escaping mysqlQueryNative, mysqlEscapeStringNative, mysqlAffectedRowsNative, mysqlInsertIdNative, mysqlBeginTransactionNative, mysqlCommitNative, mysqlRollbackNative
mysql_res.c Result set buffering, associative maps, cursor seek mysqlStoreResultNative, mysqlNumRowsNative, mysqlNumFieldsNative, mysqlGetColumnNamesNative, mysqlFetchRowNative, mysqlFetchRowAssocNative, mysqlDataSeekNative, mysqlFreeResultNative
mysql_common.h Shared type definitions & function prototypes C headers, #include <mysql.h>, #include "djazair_api.h"
Memory Safety & GC Protection: When db.close() or res.close() is called, the C bridge not only frees the underlying MYSQL* or MYSQL_RES* pointer via mysql_close() and mysql_free_result(), but also immediately sets AS_RESOURCE(arg)->ptr = NULL. This makes subsequent calls safely detect that the handle is closed rather than causing a segmentation fault.

SQL Injection Defense: Vulnerability vs. Protection

SQL Injection occurs when untrusted user input is concatenated directly into an SQL string. Below is a direct comparison between dangerous raw string concatenation and Djazair's built-in safeQuery() protection: 

# User provides malicious payload:
let userInput = "admin' OR '1'='1"

# SAFE: Using safeQuery with placeholder ?
let res = db.safeQuery("SELECT * FROM users WHERE username = ? AND is_active = 1", [userInput])

# Under the hood, Djazair safely escapes the quote:
# SELECT * FROM users WHERE username = 'admin\' OR \'1\'=\'1' AND is_active = 1
# The database treats the whole string as a literal username. Zero injection!
# User provides malicious payload:
let userInput = "admin' OR '1'='1"

# DANGEROUS: String concatenation into raw query()
let badSql = "SELECT * FROM users WHERE username = '" + userInput + "' AND is_active = 1"
let res = db.query(badSql)

# Resulting executed SQL:
# SELECT * FROM users WHERE username = 'admin' OR '1'='1' AND is_active = 1
# The attacker bypasses authentication and logs in as admin!

Common MySQL Error Codes & Resolutions

Error Code Symbolic Name Root Cause Recommended Resolution
1045 ER_ACCESS_DENIED_ERROR Invalid password or user not granted permissions for the host. Verify credentials; run GRANT ALL PRIVILEGES ON db.* TO 'user'@'%'.
2002 CR_CONNECTION_ERROR Cannot connect to MySQL server socket (service stopped or wrong port). Ensure MySQL service is running; verify port (default 3306) and host firewall.
2006 CR_SERVER_GONE_ERROR Connection timed out or packet exceeded max_allowed_packet. Check db.ping() before long-running queries; increase wait_timeout.
1062 ER_DUP_ENTRY Attempted to insert duplicate value into UNIQUE or PRIMARY key column. Handle conflict with ON DUPLICATE KEY UPDATE or check existence before insert.
1146 ER_NO_SUCH_TABLE Table does not exist in the selected database catalog. Verify database name in connection string and ensure migrations or DDL ran.
1205 ER_LOCK_WAIT_TIMEOUT Transaction lock wait timeout exceeded due to another active transaction. Keep transactions brief; call commit() or rollback() promptly.
